# 🕉️ Deepak & Sapna Wedding Invitation Website

A luxury, interactive wedding invitation website featuring a **sacred Kashi / Varanasi aesthetic**, **Canva-style motion graphics**, **full-screen responsive design**, **Google Calendar integration**, and **Google Maps venue directions**.

---

## ✨ Features

- **🌸 Sacred Kashi Theme**: Varanasi ghats at golden sunset, floating glowing diyas, temple bells, and royal traditional typography.
- **🎬 Canva Motion Edition**:
  - Live image Ken Burns breathing effect on all cards and backdrops
  - Soft light sheen overlays and flickering warm diya flame glows
  - Metallic gold foil continuous shine on headings
  - Motion particle shower (falling marigold petals + rising diya embers + golden sparkles)
- **📅 Google Calendar Integration**: One-tap "Add to Calendar" button on every ceremony card with pre-filled event details, timing, and venue.
- **📥 Apple / Outlook (.ics) Calendar Download**: Instant offline calendar file download for iOS and desktop users.
- **📍 Google Maps Directions**: Direct navigation link and venue address clipboard copy on all cards.
- **📱 Responsive & Full-Screen**: Mobile-first architecture that seamlessly expands to an alternating Z-pattern editorial showcase on tablets, laptops, and ultra-wide desktops.
- **🎵 Sacred Shehnai / Raga Ambient Synthesizer**: Built-in Web Audio API Indian classical drone & shehnai raga player with a live soundwave visualizer.
- **💬 Direct WhatsApp RSVP & Sharing**: Instant WhatsApp RSVP button with pre-formatted greetings and guest count.
- **📜 Live Warm Wishes Guestbook**: Real-time blessings wall with local storage persistence.

## 🚀 Getting Started

To run the site locally:
```bash
# Using Python
python3 -m http.server 8080

# Or using Node.js / npx
npx serve .
```

Open `http://localhost:8080` in any web browser.
